ВВЕДЕНИЕ

Почему я выбрал эту тему. Я увлекаюсь компьютерами и программированием. Мне захотелось применить свои знания на практике и сделать не просто скучную задачку в черном окне консоли, а настоящую игру, которая открывается в обычном браузере. Я выбрал шахматы, потому что это классная игра на логику, и мне стало интересно, смогу ли я сам написать в коде правила для каждой фигуры.
Цель проекта: сделать рабочую игру «Шахматы» на языке C#, в которую можно играть прямо в браузере.
Задачи проекта:
1. Выучить основы языка C#
2. Разобраться, как в программе Visual Studio сделать интерактивный сайт с помощью Blazor.
3. Нарисовать шахматную доску с помощью простых HTML-тегов.
4. Написать правила ходов для всех фигур и сделать так, чтобы игра сама определяла победителя.
Как я делал проект: читал школьный учебник, смотрел обучающие видео, придумывал логику доски, писал код и проверял его на ошибки.

1. ТЕОРЕТИЧЕСКАЯ ЧАСТЬ


1.1. Что я использовал для работы

Для создания игры я выбрал язык программирования C# и программу Microsoft Visual Studio. Чтобы игра работала как обычный сайт, я использовал технологию Blazor. Она очень удобная, потому что позволяет в одном файле соединить внешний вид страницы (HTML) и саму программу (C#). Благодаря этому мне не пришлось отдельно учить еще один язык — JavaScript.

1.2. Как мне помог учебник информатики за 9 класс

Когда я придумывал программу, я опирался на темы из учебника информатики за 9 класс (авторы Л. Л. Босова, А. Ю. Босова):
• Одномерные массивы. На шахматной доске 64 клетки. Чтобы не усложнять код, я сделал обычный одномерный массив string[] board = new string;. Это как список из 64 ячеек с номерами от 0 до 63. В каждой ячейке лежит либо значок фигуры (♙, ♖, ♘ и т.д.), либо пустота "".
• Деление и остаток от деления. Чтобы по номеру клетки (от 0 до 63) понять, в каком ряду и столбике она находится, я использовал обычное деление на 8 (y = a / 8) и остаток от деления на 8 (x = a % 8).
• Работа со строками. Чтобы программа легко понимала, где белая фигура, а где черная, я записал все белые фигурки в одну строчку whitePieces = "♙♖♘♗♕♔", а черные — в строчку blackPieces = "♟♜♞♝♛♚". Программа просто проверяет через команду .Contains(), в какой строчке находится фигура.
• Таблицы в HTML. Саму доску я нарисовал с помощью обычной таблицы на языке HTML: тег <center> ставит всё по центру, <table>, <tr> и <td> создают сетку 8 на 8, а через bgcolor я раскрасил клетки в бежевый (beige) и коричневый (brown) цвета.

2. ПРАКТИЧЕСКАЯ ЧАСТЬ (КАК УСТРОЕНА ИГРА)


2.1. Экран и управление мышкой

В самом начале кода стоят две команды: @page "/" делает шахматы главной страницей сайта, а @rendermode InteractiveServer «оживляет» страницу, чтобы она сразу реагировала на клики мышки и не перезагружалась после каждого хода.
Доска рисуется двумя циклами for (8 рядов по 8 клеток). Когда игрок нажимает на клетку, срабатывает команда @onclick и запускается функция CellClick(id). Выбранная клетка подсвечивается светло-зеленым цветом (lightgreen). Над доской всегда написано, чей сейчас ход (Ходят белые или Ходят черные).

2.2. Правила для фигур

За проверку всех правил отвечает функция CheckMove(a, b), где a — откуда идем, а b — куда идем:
1. Сначала программа проверяет, не пытается ли игрок срубить свою же фигуру.
2. Потом считает, на сколько клеток по горизонтали (dx) и по вертикали (dy) передвинулась фигура.
3. Дальше проверяются правила для каждой фигуры:
	• Пешка: ходит на 1 клетку вперед (или на 2 клетки со стартового ряда), а бьет чужие фигуры только наискосок.
	• Конь: ходит буквой «Г» (на 2 клетки в одну сторону и на 1 в другую).
	• Король: может шагнуть только на 1 клетку вокруг себя.
	• Ладья, Слон и Ферзь: чтобы они не перепрыгивали через другие фигуры, я написал две отдельные проверки — LineFree (проверка прямых линий циклом for) и DiagFree (проверка диагоналей циклом while).
Игра заканчивается, когда кто-то срубает короля соперника. Тогда переменная win становится равна true, на экране появляется надпись о победе и появляется кнопка «Новая игра», которая заново расставляет все фигуры через функцию NewGame().

ЗАКЛЮЧЕНИЕ

В итоге у меня получилось сделать полностью рабочую веб-версию шахмат на языке C#. Игра отлично открывается в браузере, правильно расставляет фигуры, следит за очередью ходов и не дает нарушать правила.
Этот проект помог мне на деле применить знания из учебника информатики за 9 класс: массивы, циклы, работу со строками и создание HTML-таблиц. А по видеоурокам я научился писать код на C# и связывать его с веб-страницей через Blazor.
Если развивать игру дальше, в нее можно добавить таймер на каждый ход, список сделанных ходов сбоку от доски или попробовать написать простого бота, чтобы играть одному против компьютера.

@page "/"
@rendermode InteractiveServer

<PageTitle>Веб версия шахматы с помощью C#</PageTitle>

<center>
    <h2>Веб версия шахматы с помощью C#</h2>
    <h3>@info</h3>

    @if (win == true)
    {
        <button @onclick="NewGame">Новая игра</button>
        <br><br>
    }

    <table border="2" cellspacing="0">
        @for (int i = 0; i < 8; i = i + 1)
        {
            <tr>
                @for (int j = 0; j < 8; j = j + 1)
                {
                    int id = i * 8 + j;
                    string bg = "beige";
                    if ((i + j) % 2 == 1)
                    {
                        bg = "brown";
                    }
                    if (id == pick)
                    {
                        bg = "lightgreen";
                    }

                    <td @onclick="() => CellClick(id)" bgcolor="@bg" width="60" height="60" align="center">
                        <font size="6">@board[id]</font>
                    </td>
                }
            </tr>
        }
    </table>
</center>

@code {
    string[] board = new string;
    string step = "white";
    string info = "Ходят белые";
    int pick = -1;
    bool win = false;

    string whitePieces = "♙♖♘♗♕♔";
    string blackPieces = "♟♜♞♝♛♚";

    protected override void OnInitialized()
    {
        NewGame();
    }

    void NewGame()
    {
        step = "white";
        info = "Ходят белые";
        pick = -1;
        win = false;

        for (int i = 0; i < 64; i = i + 1)
        {
            board[i] = "";
        }

        board = "♜"; board = "♞"; board = "♝"; board = "♛";
        board = "♚"; board = "♝"; board = "♞"; board = "♜";
        for (int i = 8; i < 16; i = i + 1)
        {
            board[i] = "♟";
        }

        for (int i = 48; i < 56; i = i + 1)
        {
            board[i] = "♙";
        }
        board = "♖"; board = "♘"; board = "♗"; board = "♕";
        board = "♔"; board = "♗"; board = "♘"; board = "♖";
    }

    void CellClick(int id)
    {
        if (win == true) return;

        string f = board[id];

        if (pick != -1)
        {
            if (CheckMove(pick, id) == true)
            {
                if (f == "♔" || f == "♚")
                {
                    win = true;
                    if (step == "white") info = "Победа белых!";
                    else info = "Победа черных!";
                }

                board[id] = board[pick];
                board[pick] = "";

                if (win == false)
                {
                    if (step == "white")
                    {
                        step = "black";
                        info = "Ходят черные";
                    }
                    else
                    {
                        step = "white";
                        info = "Ходят белые";
                    }
                }
                pick = -1;
                return;
            }
        }

        if (f != "")
        {
            if (step == "white" && whitePieces.Contains(f)) pick = id;
            else if (step == "black" && blackPieces.Contains(f)) pick = id;
            else pick = -1;
        }
        else
        {
            pick = -1;
        }
    }

    bool CheckMove(int a, int b)
    {
        string f = board[a];
        string target = board[b];

        if (target != "")
        {
            if (whitePieces.Contains(f) && whitePieces.Contains(target)) return false;
            if (blackPieces.Contains(f) && blackPieces.Contains(target)) return false;
        }

        int y1 = a / 8;
        int x1 = a % 8;
        int y2 = b / 8;
        int x2 = b % 8;

        int dx = x2 - x1;
        if (dx < 0) dx = -dx;
        int dy = y2 - y1;
        if (dy < 0) dy = -dy;

        if (f == "♙")
        {
            if (x1 == x2 && y2 == y1 - 1 && target == "") return true;
            if (x1 == x2 && y1 == 6 && y2 == 4 && target == "" && board[a - 8] == "") return true;
            if (dx == 1 && y2 == y1 - 1 && target != "") return true;
            return false;
        }

        if (f == "♟")
        {
            if (x1 == x2 && y2 == y1 + 1 && target == "") return true;
            if (x1 == x2 && y1 == 1 && y2 == 3 && target == "" && board[a + 8] == "") return true;
            if (dx == 1 && y2 == y1 + 1 && target != "") return true;
            return false;
        }

        if (f == "♘" || f == "♞")
        {
            if ((dx == 2 && dy == 1) || (dx == 1 && dy == 2)) return true;
            return false;
        }

        if (f == "♔" || f == "♚")
        {
            if (dx <= 1 && dy <= 1) return true;
            return false;
        }

        if (f == "♖" || f == "♜")
        {
            if (x1 != x2 && y1 != y2) return false;
            return LineFree(x1, y1, x2, y2);
        }

        if (f == "♗" || f == "♝")
        {
            if (dx != dy) return false;
            return DiagFree(x1, y1, x2, y2);
        }

        if (f == "♕" || f == "♛")
        {
            if (x1 == x2 || y1 == y2) return LineFree(x1, y1, x2, y2);
            if (dx == dy) return DiagFree(x1, y1, x2, y2);
            return false;
        }

        return false;
    }

    bool LineFree(int x1, int y1, int x2, int y2)
    {
        if (x1 == x2)
        {
            int min = y1;
            int max = y2;
            if (y2 < y1)
            {
                min = y2;
                max = y1;
            }
            for (int y = min + 1; y < max; y = y + 1)
            {
                if (board[y * 8 + x1] != "") return false;
            }
        }
        else
        {
            int min = x1;
            int max = x2;
            if (x2 < x1)
            {
                min = x2;
                max = x1;
            }
            for (int x = min + 1; x < max; x = x + 1)
            {
                if (board[y1 * 8 + x] != "") return false;
            }
        }
        return true;
    }

    bool DiagFree(int x1, int y1, int x2, int y2)
    {
        int sx = 1;
        if (x2 < x1) sx = -1;

        int sy = 1;
        if (y2 < y1) sy = -1;

        int x = x1 + sx;
        int y = y1 + sy;

        while (x != x2)
        {
            if (board[y * 8 + x] != "") return false;
            x = x + sx;
            y = y + sy;
        }
        return true;
    }
}
